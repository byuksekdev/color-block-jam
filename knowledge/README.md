# Knowledge

Notes on what the code cannot say. Read the one that matches the task; do not load them all.

| File | Read it when |
|---|---|
| [case-brief.md](case-brief.md) | Starting any feature, writing tests, or checking whether something is in scope. It holds the requirements and every acceptance criterion. |
| [game-reference.md](game-reference.md) | Building gameplay, the HUD or the five levels. It holds the rules, the HUD and the first five levels of the reference game. |
| [asset-notes.md](asset-notes.md) | Building a prefab or a material from the supplied art, or finding a problem in it. The README's asset feedback is written from it. |
| [decisions.md](decisions.md) | Making or questioning a structural choice, or resolving an unclear requirement. The README's architecture section is written from it. |
| [pitfalls.md](pitfalls.md) | Touching tweens, pooled objects, pause, restart, saved data or number parsing. |
Rules for a note: one topic per file, facts and reasons only, updated in the same change that makes it stale. A note that repeats what the code shows gets deleted.
